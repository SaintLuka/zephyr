Сеточная адаптация

Пороговый критерий адаптации​

Простейший критерий сеточной адаптации срабатывает на относительный перепад важных газодинамических величин, таких как плотность и давление. Введем относительные пороги разбиения по плотности ξρ+\xi^{+}_{\rho}ξρ+​ и давлению ξP+\xi^{+}_{P}ξP+​, а также относительные пороги на слияние ξρ−\xi^{-}_{\rho}ξρ−​ и ξP−\xi^{-}_{P}ξP−​. Пусть ρc\rho_cρc​, PcP_cPc​ — плотность и давление в целевой ячейке, ρk\rho_kρk​ и PkP_kPk​ — данные в kkk-ой соседней ячейке.

Для выставления флага SPLIT требуется выполнение условия хотя бы для одного соседа:

∣ρc−ρk∣>ξρ+ ρcили∣Pc−Pk∣>ξP+ Pc.|\rho_c - \rho_k| > \xi^+_\rho \,\rho_c \quad \text{или} \quad |P_c - P_k| > \xi^+_P \,P_c.∣ρc​−ρk​∣>ξρ+​ρc​или∣Pc​−Pk​∣>ξP+​Pc​.

Если пороги ξ+\xi^+ξ+ не превышены, проверяются пороги ξ−\xi^-ξ−. Для выставления флага COARSE требуется, чтобы перепады оказались меньше пороговых

∣ρc−ρk∣≤ξρ− ρcи∣Pc−Pk∣≤ξP− Pc|\rho_c - \rho_k| \le \xi^-_\rho \,\rho_c \quad\text{и} \quad |P_c - P_k| \le \xi^-_P \,P_c∣ρc​−ρk​∣≤ξρ−​ρc​и∣Pc​−Pk​∣≤ξP−​Pc​

для всех соседей. Разумное соотношение ξ−≤0.5 ξ+\xi^- \le 0.5 \, \xi^+ξ−≤0.5ξ+ (по умолчанию ξ−=0.4 ξ+\xi^- = 0.4 \, \xi^+ξ−=0.4ξ+), это позволяет избежать постоянного чередования разбиения и слияния ячеек. Типичные пороговые значения: ξρ+=ξP+=0.05\xi^+_\rho = \xi^+_P = 0.05ξρ+​=ξP+​=0.05.

Хи-критерий адаптации​

χ\chiχ-критерий адаптации вдохновлен Лёнером1. Встречается также в работах ... 23. χ\chiχ-критерий основан на оценке вторых производных. Если пороговый критерий срабатывает на больших градиентах, к примеру, на ударных волнах, то χ\chiχ-критерий позволяет захватить волновые возмущения в виде экстремумов.

Малый параметр ϵ\epsilonϵ вводится для устойчивости критерия к малым возмущениям. Величина χ\chiχ пропорциональна вторым производным, но принимает значения от 0 до 1. Значение χ\chiχ можно вычислить по плотности χρ\chi_{\rho}χρ​ или по давлению χP\chi_{P}χP​.

Для выставления флага SPLIT требуется выполнение условия хотя бы для одного соседа:

χρ>ξρ+илиχP>ξP+.\chi_{\rho} > \xi^+_{\rho} \quad \text{или} \quad \chi_{P} > \xi^+_P.χρ​>ξρ+​илиχP​>ξP+​.

Если пороги ξ+\xi^+ξ+ не превышены, проверяются пороги ξ−\xi^-ξ−. Для выставления флага COARSE требуется выполнение условий:

χρ≤ξρ−иχP≤ξP−.\chi_{\rho} \le \xi^-_\rho \quad\text{и} \quad \chi_{P} \le \xi^-_P.χρ​≤ξρ−​иχP​≤ξP−​.

Выбор пороговых значений χ+\chi^{+}χ+ и χ−\chi^{-}χ− не является универсальным и обычно подбирается под задачу.

Консервативный перенос данных​

Для выполнения адаптации необходимы функции распределения данных при слиянии и разбиении ячеек. Рассмотрим процедуру переноса данных на примере уравнений Эйлера. При слиянии ячеек выполняется консервативное суммирование:

qpVp=∑cqcVc,\mathbf{q}_p V_p = \sum_{c} \mathbf{q}_c V_c,qp​Vp​=c∑​qc​Vc​,

где qc\mathbf{q}_cqc​ и VcV_cVc​ — значения консервативного вектора состояния в дочерних ячейках и их объемы, а qp\mathbf{q}_pqp​ и VpV_pVp​ — соответствующие величины родительской ячейки.

Закон сохранения также должен выполняться при разбиении ячейки на дочерние. Один из способов этого добиться — перенести значения из родительской ячейки в дочерние qс=qp\mathbf{q}_с = \mathbf{q}_pqс​=qp​ без изменений, но в этом случае теряется точность, и такой способ не подходит для использования со схемами высокого порядка.

Другой способ — перенос величин по градиентам консервативных переменных. Закон сохранения выполнится, если выполнить перенос по формулам:

qc=qp+(∇q, rc−rp),\mathbf{q}_c = \mathbf{q}_p + (\mathbf{\nabla} \mathbf{q}, \, \mathbf{r}_c - \mathbf{r}_p),qc​=qp​+(∇q,rc​−rp​),

где rp\mathbf{r}_prp​ и rc\mathbf{r}_crc​ — барицентры родительской и дочерней ячеек. При переносе данных целесообразно использовать лимитированный градиент из родительской ячейки. Это уменьшает вероятность появления осцилляций. Поскольку задачи чаще моделируются в примитивных переменных (ρ, v, P)(\rho, \, \mathbf{v}, \, P)(ρ,v,P), получим формулы для них.

Из закона сохранения массы:

ρc=ρp+(∇ρ, rc−rp).\rho_c = \rho_p + (\mathbf{\nabla} \rho, \, \mathbf{r}_c - \mathbf{r}_p).ρc​=ρp​+(∇ρ,rc​−rp​).

Из закона сохранения импульса:

vc=vp+ρpρc(∇v, rc−rp).\mathbf{v}_c = \mathbf{v}_p + \frac{\rho_p}{\rho_c} (\mathbf{\nabla} \mathbf{v}, \, \mathbf{r}_c - \mathbf{r}_p).vc​=vp​+ρc​ρp​​(∇v,rc​−rp​).

По такой же формуле переносятся другие пассивные скаляры, к примеру, массовые концентрации в многоматериальных задачах. Из закона сохранения энергии:

ec=ep−(vp−vc)22+ρpρc(∇e, rc−rp).e_c = e_p - \frac{(\mathbf{v}_p - \mathbf{v}_c)^2}{2} + \frac{\rho_p}{\rho_c} (\mathbf{\nabla} e, \, \mathbf{r}_c - \mathbf{r}_p).ec​=ep​−2(vp​−vc​)2​+ρc​ρp​​(∇e,rc​−rp​).

Градиент внутренней энергии ∇e\mathbf{\nabla} e∇e можно выразить через уравнение состояния P(ρ, e)P(\rho, \, e)P(ρ,e) и градиенты примитивных переменных ∇ρ\mathbf{\nabla} \rho∇ρ и ∇P\mathbf{\nabla} P∇P:

∇e=(∇P−(∂P∂ρ)e⋅∇ρ)/(∂P∂e)ρ\mathbf{\nabla} e = \Bigl(\mathbf{\nabla} P - \bigl(\tfrac{\partial P}{\partial \rho} \bigr)_e \cdot \mathbf{\nabla} \rho \Bigr) / \bigl(\tfrac{\partial P}{\partial e} \bigr)_{\rho}∇e=(∇P−(∂ρ∂P​)e​⋅∇ρ)/(∂e∂P​)ρ​

Давление в дочерней ячейке восстанавливается из уравнения состояния Pc=P(ρc, ec)P_c = P(\rho_c, \, e_c)Pc​=P(ρc​,ec​). Все градиенты и производные в формулах относятся к реконструированному градиенту примитивных переменных для родительской ячейки.
