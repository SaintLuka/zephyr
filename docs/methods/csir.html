Реконструкция интерфейса

1. Постановка задачи​

Задача кусочно‑линейной реконструкции интерфейса (PLIC, Piecewise Linear Interface Calculation) является ключевой для методов моделирования многофазных течений, в частности для метода VOF (Volume of Fluid). По распределению объемных долей фазы требуется точно восстановить межфазную границу на подсеточном уровне.

Рассмотрим ячейку Ω\OmegaΩ, в которой известна объёмная доля фазы α∈(0, 1)\alpha \in (0,\,1)α∈(0,1). Необходимо найти внешнюю нормаль n\mathbf{n}n к интерфейсу и параметр ppp такие, что плоскость (в 3D) или прямая (в 2D)

(x, n)=p(\mathbf{x},\,\mathbf{n}) = p(x,n)=p

отсекает от ячейки объём (или площадь) V=α ∣Ω∣V = \alpha\,|\Omega|V=α∣Ω∣. Параметр ppp — это расстояние со знаком от центра ячейки (начала координат) до плоскости: p>0p>0p>0, если центр лежит в области (x,n)<p(\mathbf{x},\mathbf{n})<p(x,n)<p, и p<0p<0p<0 в противном случае.

Задача естественным образом распадается на два этапа:

  1. Определение нормали n\mathbf{n}n по распределению объёмных долей в окрестности ячейки.
  2. Определение положения плоскости ppp при известных α\alphaα и n\mathbf{n}n.

Вторая подзадача решается аналитически или, например, итерационными методами дихотомии/Ньютона/Брента. Основная трудность и основное влияние на точность связаны с аппроксимацией нормали1.

3. Преимущества метода CSIR​

Предлагаемый метод CSIR (Compact Stencil Interface Reconstruction) обладает следующими свойствами1:

  • Компактный шаблон — используются только соседние ячейки через грани (face neighbors). Это упрощает реализацию на адаптивных сетках и снижает объёмы MPI-пересылок.
  • Явные формулы — в двумерном случае, а также для прямой/обратной задачи в трёхмерном случае, всё записывается аналитически.
  • Локальность — решение строится в каждой ячейке независимо, нет внешних итераций по всей сетке.
  • Второй порядок точности (в 2D и для 3D‑варианта CSIR3^33).
  • Точное восстановление линейных (плоских) границ по построению.
  • Сравнимая (и на грубых сетках несколько более высокая) точность относительно ELVIRA.

αf=12[min⁡(αL,αR)max⁡(αB,αT)+max⁡(αL,αR)min⁡(αB,αT)+max⁡(αL,αR)max⁡(αB,αT)−min⁡(αL,αR)min⁡(αB,αT)].\alpha_f = \frac{1}{2}\Bigl[ \min(\alpha_L,\alpha_R)\max(\alpha_B,\alpha_T) + \max(\alpha_L,\alpha_R)\min(\alpha_B,\alpha_T) + \\ \max(\alpha_L,\alpha_R)\max(\alpha_B,\alpha_T) - \min(\alpha_L,\alpha_R)\min(\alpha_B,\alpha_T) \Bigr].αf​=21​[min(αL​,αR​)max(αB​,αT​)+max(αL​,αR​)min(αB​,αT​)+max(αL​,αR​)max(αB​,αT​)−min(αL​,αR​)min(αB​,αT​)].

Формула корректна для всех случаев, включая вырождения. Если плоскость пересекает грань по прямой, результат точен.

Итоговая нормаль. После вычисления αf\alpha_fαf​ на всех гранях:

S=−∑kαf,k Sk,n=S∥S∥.\mathbf{S} = -\sum_k \alpha_{f,k}\,\mathbf{S}_k, \qquad \mathbf{n} = \frac{\mathbf{S}}{\|\mathbf{S}\|}.S=−k∑​αf,k​Sk​,n=∥S∥S​.

При точном вычислении αe\alpha_eαe​ метод CSIR3^33 гарантирует точное восстановление плоскости, используя только соседние ячейки через грани.
