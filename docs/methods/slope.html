Реконструкция градиента

При использовании адаптивных сеток (AMR) классический метод наименьших квадратов (МНК) для реконструкции градиента приводит к нарушению симметрии при решении одномерных задач на двумерных или трехмерных сетках. Возникают ложные производные в направлениях, в которых решение не зависит от координат, что может инициировать нефизичные возмущения. В частности, это проявляется в развитии неустойчивости Рихтмайера—Мешкова даже при отсутствии начальных возмущений. Предлагаемый подход на основе симметричного МНК (сМНК) устраняет данный недостаток, сохраняя симметрию решения, повышая точность аппроксимации и обеспечивая корректный переход к одномерным конечно-разностным схемам на адаптивных шаблонах1.

1. Реконструкция градиента​

1.1. Классический метод наименьших квадратов​

Пусть на сетке задана гладкая функция uuu, значения которой относятся к центрам ячеек. Для целевой ячейки с центром в начале координат обозначим значение ucu_cuc​, а для соседней kkk-й ячейки — uku_kuk​ и радиус-вектор её центра rk\mathbf{r}_krk​. Требуется построить линейную реконструкцию u(r)=uc+(∇u, r)u(\mathbf{r}) = u_c + (\mathbf{\nabla} u, \, \mathbf{r})u(r)=uc​+(∇u,r), минимизируя функционал:

∑kωk(uc+(∇u, rk)−uk)2→min⁡\sum_{k} \omega_k \left( u_c + (\mathbf{\nabla} u, \, \mathbf{r}_k) - u_k \right)^2 \to \mink∑​ωk​(uc​+(∇u,rk​)−uk​)2→min

Задача минимизации сводится к системе линейных уравнений:

A∇u=F,A \mathbf{\nabla} u = \mathbf{F},A∇u=F, A=∑kωkrk⊗rkT,F=∑kωk(uk−uc)rk.A = \sum_{k} \omega_k \mathbf{r}_k \otimes \mathbf{r}_k^T, \qquad \mathbf{F} = \sum_{k} \omega_k (u_k - u_c) \mathbf{r}_k.A=k∑​ωk​rk​⊗rkT​,F=k∑​ωk​(uk​−uc​)rk​.

В качестве весов часто выбираются значения ωk=∣rk∣−2\omega_k = |\mathbf{r}_k|^{-2}ωk​=∣rk​∣−2. Матрица AAA симметрична и положительно определена. На декартовой сетке схема воспроизводит центральные разности. На nnn-мерной сетке матрица AAA имеет размер n×nn \times nn×n,

1.2. Симметричный метод наименьших квадратов (сМНК)​

На иерархических адаптивных сетках вектор rk\mathbf{r}_krk​ не ортогонален внешней нормали к грани. По этой причине на некоторых шаблонах может появляться ненулевая yyy-компонента при аппроксимации градиента одномерной функции f(x)f(x)f(x). Для устранения эффекта вводится проекция вектора на внешнюю нормаль к грани rk′=(rk, nk) nk.\mathbf{r}'_k = (\mathbf{r}_k, \, \mathbf{n}_k) \, \mathbf{n}_k.rk′​=(rk​,nk​)nk​.

В симметричном МНК также предлагается решать систему уравнений:

A∇u=F,A \mathbf{\nabla} u = \mathbf{F},A∇u=F,

но матрица и правая часть корректируются:

A=∑kωkrk′⊗rkT,F=∑kωk(uk−uc)rk′.A = \sum_{k} \omega_k \mathbf{r}'_k \otimes \mathbf{r}_k^T, \qquad \mathbf{F} = \sum_{k} \omega_k (u_k - u_c) \mathbf{r}'_k.A=k∑​ωk​rk′​⊗rkT​,F=k∑​ωk​(uk​−uc​)rk′​.

Также выбираются весовые коэффициенты, пропорциональные площади грани SkS_kSk​:

ωk=Sk∣rk′∣3.\omega_k = \frac{S_k}{|\mathbf{r}'_k|^3}.ωk​=∣rk′​∣3Sk​​.

Такая реконструкция не сводится непосредственно к задаче минимизации, однако обеспечивает выполнение свойства симметрии и повышенную точность на адаптивных шаблонах. Для ортогональных сеток rk′=rk\mathbf{r}'_k = \mathbf{r}_krk′​=rk​, в этом случае схемы отличаются только выбором весов.

1.3. Свойства сМНК​

  1. Линейность. Для линейной целевой функции градиент восстанавливается точно. Это справедливо и для классической схемы при произвольных весах.
  2. Аппроксимация. Схема аппроксимирует градиент с первым порядком. Для полностью симметричных ячеек порядок повышается до второго.
  3. Симметрия. Если целевая функция не зависит от xxx, а ячейка симметрична по xxx, то компонента ∂u/∂x\partial u / \partial x∂u/∂x равна нулю. Аналогично для других направлений. Это гарантирует отсутствие ложных тангенциальных производных в одномерных задачах на многомерных адаптивных сетках.
  4. Симметрия повышает точность. Если функция зависит только от xxx, а ячейка симметрична по yyy и zzz, то производная uxu_xux​ совпадает с трёхточечной формулой на неравномерной одномерной сетке и имеет второй порядок точности, при этом uy=uz=0u_y = u_z = 0uy​=uz​=0.

2. Ограничитель градиента​

Реконструкция градиента используется в схемах высокого порядка типа MUSCL23. Градиент используется для интерполяции значений на грань ячейки для дальнейшего расчета потоков. Использование обычного градиента для интерполяции приводит к появлению осцилляций, то есть к нефизичному, немонотонному поведению функций. Для борьбы с этими эффектами интерполяция проводится с использованием ограничителей производных (slope limiters). Методы интерполяции можно разделить на два класса.

  1. Интерполяционный оператор (интерполянт) строится локально в окрестности каждой грани с использованием данных пары соседних ячеек, такой метод будем обозначать как гране-ориентированный (или face-based).

  2. Интерполянт строится для всей ячейки, а интерполяция на каждую грань производится единообразно, такой метод будем называть ячейко-ориентированным (или cell-based).

2.1. Гране-ориентированная интерполяция​

Пусть в целевой ячейке задано значение ucu_cuc​ функции и градиент ∇u\mathbf{\nabla} u∇u. Требуется построить интерполяцию функции на грань ячейки. Грань между целевой ячейкой и kkk-ой соседней ячейкой обозначим как σk\sigma_kσk​, а центр грани как rkσr^{\sigma}_krkσ​.

Производная по направлению к центру соседней ячейки:

∂ku=(∇u, rk)∣rk∣.\partial_k u = \frac{(\mathbf{\nabla} u, \, \mathbf{r}_k)}{|\mathbf{r}_k|}.∂k​u=∣rk​∣(∇u,rk​)​.

Лимитированную производную ∂ˉku\bar{\partial}_k u∂ˉk​u будем вычислять на основе трех значений ∂ku\partial_k u∂k​u, ∂k−u\partial^{-}_k u∂k−​u и ∂k+u\partial^{+}_k u∂k+​u, где ∂k−u\partial^{-}_k u∂k−​u и ∂k+u\partial^{+}_k u∂k+​u являются лево- и правосторонней аппроксимациями производной ∂ku\partial_k u∂k​u в ячейке (под правосторонней понимается производная в положительном направлении вектора rk\mathbf{r}_krk​). Помимо производных введем соответствующие конечные разности:

Δk±u=∂k±u⋅∣rk∣.\Delta^{\pm}_k u = \partial^{\pm}_k u \cdot |\mathbf{r}_k|.Δk±​u=∂k±​u⋅∣rk​∣.

Производные связаны соотношением:

∂ku=∂k−u+∂k+u2⇒Δk−u+Δk+u=2(∇u, rk).\partial_k u = \frac{\partial^{-}_k u + \partial^{+}_k u}{2} \quad \Rightarrow \quad \Delta^{-}_k u + \Delta^{+}_k u = 2 (\mathbf{\nabla} u, \, \mathbf{r}_k).∂k​u=2∂k−​u+∂k+​u​⇒Δk−​u+Δk+​u=2(∇u,rk​).

Правостороннюю производную вычислим по формуле:

∂k+u=uk−uc∣rk∣,Δk+=uk−uc.\partial^{+}_k u = \frac{u_k - u_c}{|\mathbf{r}_k|}, \qquad \Delta^{+}_k = u_k - u_c.∂k+​u=∣rk​∣uk​−uc​​,Δk+​=uk​−uc​.

Тогда левосторонняя производная (с учетом известной ∂ku\partial_k u∂k​u):

∂k−u=2∂ku−∂k+u,Δk−u=2(∇u, rk)−Δk+u.\partial^{-}_k u = 2 \partial_k u - \partial^{+}_k u, \qquad \Delta^{-}_k u = 2 (\mathbf{\nabla} u, \, \mathbf{r}_k) - \Delta^{+}_k u.∂k−​u=2∂k​u−∂k+​u,Δk−​u=2(∇u,rk​)−Δk+​u.

Лимитированная производная ∂ˉku\bar{\partial}_k u∂ˉk​u определяется на основе трёх оценок и выбранной функции ограничителя limiter:

∂ˉku=limiter(∂ku, ∂k−u, ∂k+u)=ϕ(θk) ∂k+u,θk=∂k−u∂k+u.\bar{\partial}_k u = \mathrm{limiter} \bigl(\partial_k u, \, \partial^{-}_k u, \, \partial^{+}_k u \bigr) = \phi (\theta_k) \, \partial^{+}_k u, \qquad \theta_k = \frac{\partial^{-}_k u}{\partial^{+}_k u}.∂ˉk​u=limiter(∂k​u,∂k−​u,∂k+​u)=ϕ(θk​)∂k+​u,θk​=∂k+​u∂k−​u​.

или в конечных разностях

Δˉku=limiter(Δku, Δk−u, Δk+u)=ϕ(θk) Δk+u,θk=Δk−uΔk+u.\bar{\Delta}_k u = \mathrm{limiter} \bigl(\Delta_k u, \, \Delta^{-}_k u, \, \Delta^{+}_k u \bigr) = \phi (\theta_k) \, \Delta^{+}_k u, \qquad \theta_k = \frac{\Delta^{-}_k u}{\Delta^{+}_k u}.Δˉk​u=limiter(Δk​u,Δk−​u,Δk+​u)=ϕ(θk​)Δk+​u,θk​=Δk+​uΔk−​u​.

здесь ϕ(θ)\phi(\theta)ϕ(θ) — одномерная функция ограничителя. Некоторые варианты ограничителей:

  • minmod: ϕmm(θ)=max⁡(0,  min⁡(θ,  1));\phi_{mm}(\theta) = \max\bigl(0,\; \min(\theta,\; 1)\bigr);ϕmm​(θ)=max(0,min(θ,1));
  • MC (monotonized central)4: ϕmc(θ)=max⁡(0,  min⁡(2θ,  1+θ2,  2));\phi_{mc}(\theta) = \max\left(0,\; \min\left(2\theta,\; \frac{1+\theta}{2},\; 2\right)\right);ϕmc​(θ)=max(0,min(2θ,21+θ​,2));
  • van Albada5: ϕva1(θ)=θ2+θθ2+1 η(θ),ϕva2(θ)=2θθ2+1 η(θ).\phi_{va1}(\theta) = \frac{\theta^2 + \theta}{\theta^2 + 1}\,\eta(\theta), \qquad \phi_{va2}(\theta) = \frac{2\theta}{\theta^2 + 1}\,\eta(\theta).ϕva1​(θ)=θ2+1θ2+θ​η(θ),ϕva2​(θ)=θ2+12θ​η(θ).

Лимитированные значения uˉkσ\bar{u}^{\sigma}_kuˉkσ​ на гранях со стороны целевой ячейки:

uˉkσ=uc+Δˉku ∣rkσ∣∣rk∣.\bar{u}^\sigma_k = u_c + \bar{\Delta}_k u \,\frac{|\mathbf{r}^\sigma_k|}{|\mathbf{r}_k|}.uˉkσ​=uc​+Δˉk​u∣rk​∣∣rkσ​∣​.

Существуют и более сложные способы построения лимитированной производной. В работе Томаса, Андерсона и ван Лира 6 построена монотонная интерполяция третьего порядка. Для неструктурированных сеток она имеет следующий вид7:

Δˉku=12s[(1−κs) Δk−u+(1+κs) Δk+u],s=ϕva2(θk),\bar{\Delta}_k u = \frac{1}{2} s \bigl[(1 - \kappa s) \, \Delta^{-}_k u + (1 + \kappa s) \, \Delta^{+}_k u \bigr], \qquad s = \phi_{va2} (\theta_k),Δˉk​u=21​s[(1−κs)Δk−​u+(1+κs)Δk+​u],s=ϕva2​(θk​), κ=12δ2−112δ,δ=∣rkσ∣∣rk∣,s=2Δk−Δk+(Δk−)2+(Δk+)2.\kappa = \frac{12\delta^2 - 1}{12 \delta}, \qquad \delta = \frac{| \mathbf{r}^{\sigma}_k |}{| \mathbf{r}_k |}, \qquad s = \frac{2\Delta^{-}_k \Delta^{+}_k}{(\Delta^{-}_k)^2 + (\Delta^{+}_k)^2}.κ=12δ12δ2−1​,δ=∣rk​∣∣rkσ​∣​,s=(Δk−​)2+(Δk+​)22Δk−​Δk+​​.

Формула позволяет получить интерполяцию на центр грани. Формула справедлива если центр грани rkσ\mathbf{r}^{\sigma}_krkσ​ лежит на отрезке, соединяющем центры смежных ячеек. Также формула не позволяет интерполировать значения в произвольные точки ячейки, хотя такая задача возникает при использовании сеточной адаптации. Когда крупная ячейка разбивается на несколько небольших ячеек, значения в новых ячейках целесообразно получать путем интерполяции из родительской ячейки. Данные проблемы решает метод интерполяции на основе лимитированного градиента.

2.2. Ячейко-ориентированная интерполяция​

Попробуем отыскать градиент ∇u\mathbf{\nabla} u∇u, который бы удовлетворял уравнениям системы:

∀k(∇u, rk)=uk−uc=Δk+u.\forall k \qquad (\mathbf{\nabla} u, \, \mathbf{r}_k) = u_k - u_c = \Delta^{+}_k u.∀k(∇u,rk​)=uk​−uc​=Δk+​u.

Эта переопределенная система. После добавления весовых коэффициентов ωk\omega_kωk​ и сведения к задаче минимизации мы получаем классический МНК.

Пусть теперь мы хотим определить в ячейке лимитированный градиент ∇ˉu\bar{\mathbf{\nabla}} u∇ˉu, который можно было бы использовать для интерполяции значений из центра в любую точку целевой ячейки. Потребуем, чтобы лимитированный градиент удовлетворял аналогичным уравнениям, но с лимитированными приращениями:

∀k(∇ˉu, rk)=Δˉku=ϕ(θk) Δk+u.\forall k \qquad (\bar{\mathbf{\nabla}} u, \, \mathbf{r}_k) = \bar{\Delta}_k u = \phi(\theta_k) \, \Delta^{+}_k u.∀k(∇ˉu,rk​)=Δˉk​u=ϕ(θk​)Δk+​u.

Новая система уравнений отличается только добавлением коэффициента ϕ(θk)\phi(\theta_k)ϕ(θk​), можем применить для решения стандартный или симметричный МНК:

A∇ˉu=Fˉ,A \bar{\mathbf{\nabla}} u = \bar{\mathbf{F}},A∇ˉu=Fˉ, A=∑kωkrk′⊗rkT,F=∑kωkϕ(2(∇u, rk)uk−uc−1)(uk−uc)rk′,ωk=Sk∣rk′∣3.A = \sum_{k} \omega_k \mathbf{r}'_k \otimes \mathbf{r}_k^T, \qquad \mathbf{F} = \sum_{k} \omega_k \phi \Bigl( \tfrac{2(\mathbf{\nabla} u, \, \mathbf{r}_k)}{u_k - u_c} - 1 \Bigr) (u_k - u_c) \mathbf{r}'_k, \qquad \omega_k = \frac{S_k}{|\mathbf{r}'_k|^3}.A=k∑​ωk​rk′​⊗rkT​,F=k∑​ωk​ϕ(uk​−uc​2(∇u,rk​)​−1)(uk​−uc​)rk′​,ωk​=∣rk′​∣3Sk​​.

вектор rk′=(rk, nk) nk\mathbf{r}'_k = (\mathbf{r}_k, \, \mathbf{n}_k) \, \mathbf{n}_krk′​=(rk​,nk​)nk​.

Таким образом, для вычисления лимитированного градиента в ячейке сначала необходимо реконструировать обычный градиент ∇u=A−1F\mathbf{\nabla} u = A^{-1} \mathbf{F}∇u=A−1F, затем рассчитывается лимитированный ∇ˉu=A−1Fˉ\bar{\mathbf{\nabla}} u = A^{-1} \bar{\mathbf{F}}∇ˉu=A−1Fˉ. Вычисление лимитированного градиента не требует значительного увеличения вычислительных ресурсов. Матрица AAA вычисляется только один раз. При этом между вычислением обычного и лимитированного градиента не требуется синхронизация потоков (при многопоточном выполнении) или обменные операции (при параллелизации с распределенной памятью), поскольку из соседних ячеек в обеих операциях требуются только значения uku_kuk​.

После получения лимитированного градиента, интерполяция в любую точку ячейки осуществляется единообразно:

u(r)=uc+(∇ˉu,r).u(\mathbf{r}) = u_c + (\bar{\nabla} u, \mathbf{r}).u(r)=uc​+(∇ˉu,r).

в частности, эту формулу можно использовать для интерполяции на грань ячейки, или для интерполяции данных родительской ячейки в дочерние при адаптации.
